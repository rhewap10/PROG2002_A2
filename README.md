# Inventory TypeScript App

Simple browser-based inventory system implemented in TypeScript. This project also includes an Angular skeleton (see `angular_app`) that can be copied into a real Angular project.

Getting started:

1. Install dependencies:

```powershell
npm install
```

2. Build TypeScript (compiles `ts/` into `src/js/`):

```powershell
npm run build
```

3. Run locally (opens `src/index.html` on port 8080):

```powershell
npm start
```

Notes:
- The app stores data in `localStorage` under `inventory_items`.
- The Angular folder contains example service and component snippets you can paste into an Angular CLI project.
